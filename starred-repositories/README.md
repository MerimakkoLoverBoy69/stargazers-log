# Starred Repositories

This project displays a list of starred repositories using data fetched from a JSON file. It consists of an HTML file, a CSS file for styling, a JavaScript file for functionality, and a JSON file containing sample data.

## Project Structure

```
starred-repositories
├── index.html        # Main HTML document
├── events.json       # Sample data for starred repositories
├── style.css         # Styles for the repository list
├── script.js         # JavaScript to fetch and render data
└── README.md         # Project documentation
```

## Getting Started

To set up this project locally, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd starred-repositories
   ```

3. **Open `index.html` in your web browser** to view the starred repositories page.

## Usage

The application fetches data from `events.json` and displays a list of starred repositories. Each repository includes the name, owner, description, and a link to the repository.
